Icônes des projets

Projet ouvert — celui qui est affiché dans l'éditeur.
Sur cet appareil — copie locale. Si c'est la seule icône de lieu, le projet n'est pas sur le Cloud.
Sur le Cloud — une version est sauvegardée sur GitHub. Sans l'icône appareil, le projet n'est pas stocké ici.
Synchronisé — l'appareil et le Cloud sont identiques.
À sauvegarder — modifié depuis la dernière sauvegarde Cloud (envoi automatique après 30 s sans frappe).
À récupérer — le projet, ou une version plus récente, est sur le Cloud. Touchez la ligne pour le récupérer et l'ouvrir.
Conflit — modifié ici ET sur le Cloud. Rien n'est écrasé : touchez « Résoudre le conflit ».
Corbeille du Cloud — « Restaurer » le récupère, « Supprimer » l'efface définitivement.
Touchez un projet pour l'ouvrir. « ⋯ » ouvre les actions : versions, renommer, retirer, corbeille, supprimer partout.
